About

Built by developers,
for developers.

LogLabs is an independent software lab. We build tools for developers who live in the terminal and want their workflow to feel precise and fast.

We ship both free open source tools and premium software — because great tooling deserves to be sustainable. Open source is at our core, but some projects will be paid products.

We target Arch Linux first. Not because it's the only platform that matters — but because users there demand quality, and quality travels.

# manifesto.txt

→ Build sharp tools.
→ Obsess over details.
→ Respect the user's time.
→ Open source when possible.
→ Premium when it makes sense.
→ Never add bloat.
